# Yuly Sánchez — Skin & Beauty

Offline-first business management app for a skin & beauty studio.

## What it does

- Appointment and client bookkeeping
- Service and product catalog
- Local-only data: everything stays on the owner's device (no cloud account, no remote database)
- Printable/exportable summaries for daily operations

## Privacy

This app was built **local-data only** by design. Client information never leaves the device,
and there is no backend service to breach or subscribe to.

## Status

Private-use business app. This public repository is a showcase; the production build and client data
stay private.
